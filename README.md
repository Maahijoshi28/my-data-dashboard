# Global Development Dashboard

An interactive web-based data dashboard designed to analyze and visualize long-term trends in global development. This project utilizes the Gapminder dataset to explore the relationship between GDP per capita, life expectancy, and population growth over time.

## 💡 Project Overview
This dashboard performs Exploratory Data Analysis (EDA) on multi-dimensional variables to provide actionable insights. By using an interactive web interface, users can filter data by continent and year to identify correlations between economic health and public welfare outcomes from 1952 to 2007.

## 🛠 Features
* **Interactive Visualizations:** Powered by Plotly for dynamic, hover-able, and zoomable charts.
* **Temporal Analysis:** A dynamic slider to view changes in global development trends.
* **Custom Filters:** Sidebar controls to filter data by continent and year.
* **Deployment:** Hosted as a scalable web application via Streamlit Cloud.

## 💻 Tech Stack
* **Language:** Python
* **Web Framework:** Streamlit
* **Data Manipulation:** Pandas
* **Visualization:** Plotly
* **SOURCE:** The Gapminder dataset you are using for your project comes from the Gapminder Foundation, a non-profit organization based in Stockholm, Sweden
